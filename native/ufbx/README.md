# ufbx

Single-file FBX loader by Samuli Raivio, <https://github.com/ufbx/ufbx>, version 0.23.1
(`ufbx.c`, `ufbx.h` and `LICENSE` copied unchanged from the `v0.23.1` tag). MIT or public
domain, see `LICENSE`.

Used by `../fbx_reader.c`, which `hook/build.dart` compiles into the app. To update, replace
the three files with those of a newer tag and run the FBX tests (`test/core/model_fbx_test.dart`).
